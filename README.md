A port for (Vague)[https://github.com/vague-theme/vague/] theme for Nushell generated by AI following the pattren on (nushell/nu_scripts repo)[https://github.com/nushell/nu_scripts].

# Use & Install

first fetch the script:
```nu
let install_dir = ~/.local/share/nushell/themes/; # change base on where u want to install the theme.
mkdir $install_dir;
http get https://github.com/abdelkadouss/vague.nu/raw/refs/heads/main/vague.nu | save $install_dir
```

then on ur config add:

```nu
use ~/.local/share/nushell/themes/vague.nu; # or the path to the theme where u install it

# optionaly if you want you can override the default colors like so:
# $env.config.color_config.background = "#000000";
# $env.config.color_config.cursor = "#ffffff"

vague set color_config;
vague update terminal; # optional but recommended (change the terminal colors to match)
```
